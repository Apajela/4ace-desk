# 4Ace Desk ERP PH — requested UI and payroll updates

- Removed checklist entry field, sample checklist placeholder items, and In-Charge label from priority creation/details.
- Removed the DTR/payroll computation explainer from the attendance page.
- Added a Full Access workflow to link an existing regular account when registering a crew member.
- Payroll counts one worker-day per calendar date even if attendance has multiple project records; project labor allocation splits a day's cost across distinct projects for that worker/date.
- New crew payroll entries start at zero days/pay until attendance is saved.
- Weekly payroll can be released any day; status text uses Paid / Unpaid / Not Paid; added View Payroll and simplified Save/Payslips button labels.
- Reports now show Project Contract Sum, Actual Material Cost since project start, Actual Labor Cost, Total Actual Cost, and Physical Progress in the requested order. Full Access can manually update progress, which is shared with the dashboard.
- Materials ledger includes material expenses dated on/after the project start date. Daily Site Priority Log no longer displays the cost/progress/man-hours summary cards or the Inspection checks count.
- Export remains capped at 8 records per category; import cap is aligned to 8 records per category.
- Today Priorities has no Inspection Board explanatory paragraph.

Validation: TypeScript/TSX syntax transpilation passed for 29 source files. A full Vite production build could not be run in this environment because dependency installation was unavailable; run `npm.cmd install` and `npm.cmd run build` on the Windows project folder before deployment.
